# SHTheads

The "Reverse Angie's List" for tradesmen. Built with Flutter Web.

## 🚀 Deployment Instructions

If you are seeing this page on `https://domusgpt.github.io/SHTheads/` instead of the actual web application, you need to configure your GitHub Pages settings to use **GitHub Actions**.

1. Go to your repository on GitHub.
2. Click on the **Settings** tab.
3. On the left sidebar, click on **Pages**.
4. Under the **Build and deployment** section, look for **Source**.
5. Change the source drop-down from "Deploy from a branch" to **GitHub Actions**.
6. GitHub Actions will now automatically build and deploy the app. Wait a few minutes for the workflow to finish, and refresh the page!

## Local Development

1. Ensure you have Flutter installed.
2. Run `flutter pub get`
3. Run `flutter run -d chrome`
